# v0.17.4

The rare, unsplittable pauses now announce themselves. When the world has to
think for a moment -- a province changing hands, a brand-new trade route's
first path search, a settlement project finishing -- the map shows a small
"the world is thinking…" caption for exactly as long as the freeze lasts,
instead of just freezing.

- **NEW: a "the world is thinking…" marker on the unsplittable phases.** The
  marker is painted a moment before the phase runs and removed right after, so
  it only ever appears on a step that actually takes long enough to be felt --
  the fast daily steps never flicker it. What used to look like the game
  dying now reads as the world being busy.

The world itself is unchanged: a day is still a day, saves load as before.
